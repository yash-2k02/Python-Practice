# FastAPI E-commerce API (SQLModel + MySQL)

This project is a simple **E-commerce API** built using **FastAPI**, **SQLModel**, and **MySQL**.  
It demonstrates how to build a modular FastAPI project with models, relationships, and CRUD operations.

---

## Features

- Customer Management (CRUD)  
- Product Management (CRUD)  
- Order Management (CRUD + relationships)  
- Invoice Management (linked with orders, with payment tracking)  
- Audit fields (`created_at`, `updated_at`, `created_by`, `updated_by`, `is_deleted`) with automatic listeners  
- MySQL database connection using **SQLModel**  
- Modular project structure with routers and models
